# シフト便：グループLINEからシフト提出 → Excelに反映

**名前と時間を後から入れる日別表（キッチン8人・ホール10人）に対応するベータ版を追加しました。[日別表の手順はこちら](DAILY_BETA.md)。** 管理画面の「日別表」リンクを使ってください。以下の月別表モードも残しています。

日別表は「管理者が確認して指定」と「平日・土日祝の固定休憩を自動入力」の2モードを選んで保存できます。既存のPC版をお使いの方は、[名前と提出内容を残す更新手順](UPDATE.md)を確認してください。

勤務・休憩の時間は全角の `１７：００` でも入力でき、半角の `17:00` に自動変換します。氏名の表記はそのまま残します。

グループLINEに提出リンクを貼り、スタッフがスマホのブラウザでシフト希望を送るアプリです。管理者はバイト先PCのブラウザで提出内容を集め、Excelの指定シートへ反映したコピーをダウンロードできます。

**まず仮のグループLINEで試したい方へ： [ベータテスト手順](BETA.md)** を用意しました。同梱の `beta-sample-2026-11.xlsx` と架空の氏名で、本番と分けて試せます。

## 使う流れ

1. 管理画面の「スタッフ用リンク」をグループLINEに送ります。
2. スタッフはリンクを開き、氏名・対象月・各日の希望時間や休みを入力して提出します。
3. 管理者はバイト先PCで管理画面を開き、対象月のExcelを選びます。
4. 「対象月の提出を読み込む」を押し、反映先シートと表の位置を指定します。
5. 「反映内容を確認する」で氏名・日付・セルを確認します。
6. 「反映済みExcelをダウンロード」を押します。Excelで内容を確認し、必要なら元のシフト表と差し替えます。

**元のExcelへの直接書き込みは行いません。** PCのファイルを直接・自動更新する機能はなく、選択・確認・ダウンロードの操作が必要です。

## 最初に：お試しと本番の違い

- **自分のPCで試す**：下の手順でPythonを入れて起動します。提出画面も管理画面も同じPCで使えます。スマホからは開けません。
- **LINEでスタッフに配る**：インターネット上の公開サーバーに設置する必要があります。[DEPLOY.md](DEPLOY.md)に手順があります。公開後、スタッフとバイト先PCにはPythonのインストールは不要です。どちらもブラウザだけで使えます。

このリポジトリには必要なアプリのファイルを用意していますが、公開サーバーの契約・公開URLの発行はまだ行っていません。

## 自分のPCでの実行方法（Windows / 初心者向け）

1. Python 3.12以降を https://www.python.org/downloads/ からインストールします。「Add python.exe to PATH」とPython Launcherの項目があれば有効にします。
2. プロジェクトフォルダーをPCにコピーします。GitHub上に保存した場合は「Code → Download ZIP」で取得して展開できます。`.venv`はPCごとに作るためコピー不要です。
3. **setup.bat** をダブルクリックします。初回はインターネット接続が必要です。`Setup complete`と出たら準備完了です。
4. **start.bat** をダブルクリックします。開いた黒い画面はそのままにします。
5. 同じPCのEdgeやChromeで、アドレス欄に **http://127.0.0.1:8000** と入力します。
6. 終了するときは黒い画面で **Ctrl+C** を押します。

`py`が見つからない場合はPython Launcherを含めてPythonをインストールし直すか、下のコマンド手順を使ってください。Windows用バッチはWindows実機では未検証です。

### コマンドで起動する場合

ターミナルをプロジェクトのフォルダーで開きます。Windows：

```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe app.py
```

macOS / Linux：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

起動後は同じPCのブラウザで `http://127.0.0.1:8000` を開きます。職場のPCにソフトをインストールする場合は職場のルールに従ってください。

## お試しデータで動かす

1. 管理画面で対象月を選び、「対象月のお試しExcelをダウンロード」を押します。
2. ダウンロードしたExcelをファイル欄で選択します。シート「シフト表」と表の位置の初期設定を使います。
3. 「提出画面を試す」を押します。氏名に **山田 太郎**、管理画面と同じ対象月を入力し、20日を「出勤可」「17:00〜22:00」にして提出します。
4. 管理画面に戻り、「対象月の提出を読み込む」を押します。
5. 「反映内容を確認する」を押して内容を確認し、「反映済みExcelをダウンロード」を押します。
6. Excelで20日の山田太郎の欄に `17:00-22:00` が入っていることを確認します。

スタッフ画面からの提出の代わりに、「対象月の入力例を入れる」で転記だけ試すこともできます。

## シフト提出のルール

- 氏名はExcelと同じ表記で入力します。氏名の全角・半角の空白は無視します。あだ名から本名への変換はありません。
- 「未入力」の日は提出に含みません。「出勤可」は開始・終了時刻を入力します。「休み」も選べます。
- **再提出は、同じ氏名・同じ月の最新の提出全体を採用します。変更日だけでなく、その月の希望全体を再提出してください。** 過去の提出はDBに履歴として残ります。
- 再提出で取り除いた日はExcelの既存セルから自動削除しません。既に反映した表を修正する場合は、必要な日に明示的に「休み」を入力するかExcelで調整してください。
- 提出はシフト「希望」です。勤務確定・必要人数の調整・勤務時間の自動割り当ては行いません。
- 日をまたぐ勤務、1日に複数の時間帯、同姓同名を別人として扱う機能は未対応です。
- スタッフの本人認証はありません。提出リンクを知る人が氏名を入力して提出できます。同じ氏名での再提出も可能なので、リンクはグループ内で管理し、責任者が内容を確認してください。

## Excelの設定

「縦に氏名、横に日付」の表に対応します。

| 氏名 | 10/20 | 10/21 |
|---|---|---|
| 山田 太郎 |  |  |
| 佐藤 花子 |  |  |

この例では、日付行=`1`、氏名列=`A`、氏名開始行=`2`、日付開始列=`B`です。

たとえばB列の4行目から氏名、D列の3行目から日付なら、日付行=`3`、氏名列=`B`、氏名開始行=`4`、日付開始列=`D`に変えます。シート名はファイルを読み込むと選択できます。実際の職場のExcelでの配置は未確認なので、最初はコピーを使って試してください。

日付見出しはExcelの日付、日だけの整数、`10/20`、`2026-10-20`、`20日`に対応します。日だけの場合は選択した対象月として扱うため、対象月とシートを必ず確認してください。

氏名・日付が見つからない場合、氏名・日付が重複する場合、書き込み先が数式・結合セルの場合、シートが保護されている場合は処理を中止します。一部だけを書き込むことはしません。値があるセルの変更には、確認画面で上書きの許可が必要です。

`.xlsx`のみ、8MB以下に対応します。`.xls`、マクロ付き`.xlsm`、暗号化ファイルは未対応です。図形など一部の高度なExcel機能は保持できない場合があるため、出力を確認してから使ってください。

### LINEの文章を直接貼り付けたいとき

管理画面の入力欄は次の形式にも対応しています。

```text
山田 太郎 10/20 17:00-22:00
佐藤 花子 10/21 休み
```

1行に1人・1日分です。あいさつや送信時刻は削除してください。自由文を自動解釈する機能はありません。LINEのAPI接続やLINE公式アカウントは、このリンク提出方式では不要です。

## データの保存と管理

提出された氏名・対象月・日時は `data/shifts.sqlite3` に保存します。公開時は永続ディスクの保存先を指定してください。再起動後も残りますが、ディスクを削除すれば失われます。DBのバックアップと不要な履歴の削除は管理者が行ってください。削除用画面は未実装です。

Excel自体は読み込みと出力処理の間だけメモリー上で扱い、サーバーのファイルには保存しません。公開時にはExcelが公開サーバーに送信されるので、職場が許可したサーバーでのみ使ってください。分析サービスや外部CDNは使いません。公開時の提出データ閲覧とExcel操作は管理者ログインが必要です。

## よくある問題

- **スマホでリンクを開けない**：`127.0.0.1`や`localhost`のリンクは同じPCでのお試し用です。スタッフに配るには[公開手順](DEPLOY.md)を実施します。
- **ポート8000が使用中**：既に起動した画面を使うか、仮想環境のPythonで`app.py --port 8001`を起動し、ブラウザもポート8001に変えます。
- **Excelに氏名・日付が見つからない**：対象月・シート名・表の位置・氏名の表記を確認します。
- **反映後のファイルが見つからない**：ブラウザのダウンロード一覧を確認します。元のExcelの場所に自動保存する方式ではありません。
- **管理画面でログインを求められる**：公開サーバーの`SHIFT_ADMIN_PASSWORD`でログインします。この値はスタッフに配りません。

## 開発者向け

```sh
.venv/bin/python -m unittest discover -s tests -v
```

Windowsでは`.venv/bin/python`を`.venv\Scripts\python.exe`に読み替えます。

`app.py`：Webサーバー・提出保存・管理者認証、`shifts.py`：Excel処理、`static/`：画面、`tests/`：動作テスト、`Dockerfile`：公開サーバー用、`setup.bat` / `start.bat`：Windows用です。
